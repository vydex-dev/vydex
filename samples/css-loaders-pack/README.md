# CSS Loaders Pack

8 loading spinners in **one CSS file**. Each loader is a single element, no
JavaScript, size and color controlled by variables.

## Use it
```html
<link rel="stylesheet" href="loaders.css" />

<div class="ld ld-ring"></div>
<div class="ld ld-dots"></div>
```

Resize / recolor per instance — loaders inherit `currentColor`:
```html
<div class="ld ld-ring" style="--ld-size: 48px; color: hotpink"></div>
```

## The set
`ld-ring` · `ld-dots` · `ld-bars` · `ld-pixel` (retro) · `ld-dual` ·
`ld-flip` · `ld-pulse` · `ld-type` (typewriter ellipsis)

Open `index.html` for a live gallery — click any tile to copy its snippet.
