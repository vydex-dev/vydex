Questions, answered

Do I need a build step?

No. It's plain HTML and CSS. Open the file, edit, deploy anywhere that serves static files.

How do I change the colors?

Edit the four variables at the top of style.css — accent, background, surface and text. The whole page re-themes.

Can I add my own sections?

Yes — every section is a self-contained block. Copy one, change the content, done.

Is it accessible?

Semantic landmarks, native accordions, visible focus states and AA-contrast defaults.
