# JSON Toolbox

Format, validate and minify JSON — entirely in your browser. Nothing is uploaded
anywhere, which makes it safe for API keys, tokens and private payloads.

## Features
- **Format / Minify** with one click
- **Precise errors** — invalid JSON reports the exact `line:column`
- **Structure stats** — size, node count and nesting depth, live as you type
- **Copy** the result to the clipboard
- **Zero dependencies** — vanilla HTML/CSS/JS

## Run it
Open `index.html` in any browser.

## Why not an online formatter?
Most online JSON tools send your payload to a server. This one can't — there is
no server. Check the network tab: zero requests.
